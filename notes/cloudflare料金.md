# Cloudflare の料金（2026年8月時点で確認）

## 前提: Cloudflare は「製品の集まり」

「Cloudflare は無料か」は答えられない。**製品ごとに料金体系が違う**ため。
HTMLアプリを置く用途で関係するのは次の4つだけ。

| 製品 | 何をするもの | 無料枠 | 有料 |
|---|---|---|---|
| **Pages** | 静的サイトの置き場（GitHub Pages 相当） | **無料。サイト数・通信量・アクセス数すべて無制限。更新は月500回まで** | Workers 有料 $5/月で更新5,000回 |
| **Access** | サイトに鍵をかける（メール認証） | **50人まで無料** | それ以上は人数課金 |
| **Registrar** | ドメインの取得 | 無料ではない | **原価販売。`.com` は年 $10前後（約1,500円）** |
| CDN / WAF 本体 | 速度・防御の強化 | Free $0 | Pro $20/月、Business $200/月 |

## 使う側にとっての結論

**HTMLアプリを置くだけなら、Pages の無料枠で完全に足りる。**
月500回の更新は「1日16回アプリを直す」ペース。まず超えない。
通信量もアクセス数も無制限なので、人が増えても無料のまま。

**お金がかかるのは「鍵をかけたいとき」だけ。**
Access 自体は無料だが、`〇〇.pages.dev` には鍵をかけられないため
独自ドメインが必要になる（年1,500円ほど）。→ `html-tool運用.md` 参照。

## 間違えやすい点

- **Pro（$20/月）は速度・防御の強化プランで、置き場所の話ではない。**
  個人のHTMLアプリには一切不要
- **有料プランは「ドメイン1個あたり」の課金**（Cloudflare 用語で zone = ドメイン）。
  アカウント単位ではない
- **Registrar を使うと Cloudflare のネームサーバーを使うことが必須**になる
- Pages に「動く処理」（Functions）を足すと、そこは Workers の無料枠
  （1日10万リクエスト）で数えられる。静的HTMLだけなら関係ない

## GitHub Pages との比較

| | GitHub Pages | Cloudflare Pages |
|---|---|---|
| 費用 | 無料 | 無料 |
| Private リポジトリから公開 | 有料プランが必要 | **無料でできる** |
| サイトに鍵をかける | **不可**（Enterprise のみ） | 独自ドメインがあれば可 |
| 更新のしやすさ | Safari で直接編集できる | GitHub 連携か手動アップロード |
| 設定の手間 | **少ない** | やや多い（アカウント作成が要る） |

**まず GitHub Pages で足りる。** Cloudflare が要るのは鍵をかけたくなったとき。
