# DB更新（配送統計マスター）を Claude で行う手順

最終更新: 2026-08-25
初回実施: 2026-08-25（この部屋のセッションで実証済み）

## 現在の方針（2026-08-25 オーナー決定）

**差分ファイルは作らない。いきなりマスターを書き出す。**

差分 → マスター統合、とい2段構えをやめ、
`detail_master.csv` を受け取ったら**その場でマスターの新版を出す**。
差分ファイルは中間生成物でしかなく、統合の手間が増えるだけだったため。

**旧マスターは消さずに残す。** 当面はロールバックできる状態を保つ。
ファイル名に日付が入るので、放っておけば自然に世代が並ぶ。

```
配送統計マスター_260822.csv   ← 残す
配送統計マスター_260825.csv   ← 残す
配送統計マスター_260827.csv   ← 最新
```

古い世代の整理は、運用が安定してから改めて判断する（今は消さない）。

- **AL差分（旧・出力②）は廃止**
- 統計差分（旧・出力①）も**廃止**。マスター直書きに一本化

## 手順

1. `detail_master.csv` を受け取る
2. 最新の `配送統計マスター_YYMMDD.csv` を読む
3. Python で当日1行を計算し、マスターに追加した新版を作る
4. 検算（下記）を全部通す
5. `00_Apple稼働`（folderId `15Zsw37iAiwshImKeD38KMf5Nc43fNejM`）に
   `配送統計マスター_（当日）.csv` を **`text/csv` を明示**して新規作成
   （スプレッドシートへの自動変換を無効にする。変換されると書式が壊れる）
6. **旧マスターはそのまま残す**

ツール：`tools/merge_stats.py`（マスター＋差分／マスター＋マスターのどちらでも合流できる）

## 当日中に修正が入った場合

キャンセル・種別変更・件数変更が入ったら、当日行を再計算して**枝番付きで作り直す**。

```
配送統計マスター_260825.csv → 配送統計マスター_260825b.csv
```

日付行の側も `260825` → `260825b` になる。同一日付は**枝番が最も後のものを採用**する。

## 書式（仕様書 ver.1.0 準拠）

- 列は8つ。`日付,配送総件数,集荷総件数,古山配送件数,古山集荷件数,特殊配送パターン,料金内訳(推定),料金合計(推定)`
- 料金内訳は**内訳列挙型**（`M10S10×5=5000, ...`）。サマリ型は使わない
- 特殊配送パターンは `M10 S10` を除く配送のみ。M昇順→S昇順
- 総数が不明な日は **0ではなく空欄**
- UTF-8 **BOMなし**・改行 LF

料金：
- 配送 `1000 + 600 × max(0, floor((4M + 3S − 35) / 95))`
- 集荷 一律 `1000`

## 検算（毎回すべて通す）

- 既存行が**1セルも変わっていない**こと（旧マスターと突き合わせ）
- 追加行の担当件数が明細の行数と一致
- 日付が昇順・同一日付の重複なし
- 全行で `料金内訳の合計 == 料金合計列`
- 特殊配送パターンに `M10 S10` と集荷が混入していない
- アップロード後、**ファイルサイズが手元と一致**しているか確認

## 入力ファイルの注意

- Excel 由来の CSV は先頭に **BOM**（見えない目印バイト）が付いていることがある。
  Python では `encoding="utf-8-sig"` で読めばどちらでも壊れない
- `.xlsx` は中身が ZIP なので BOM は存在しない。直接読む分には無関係
