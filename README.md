# 兄貴の部屋

質問して、答えをもらって、残しておく部屋。

Git / GitHub / Claude Code のことが中心だが、話題は問わない。
「これ何？」と思ったら、ここで聞く。

---

## 使い方

Claude Code で新しいセッションを開き、このリポジトリを選んで、聞くだけ。

`CLAUDE.md` が自動で読まれるので、**毎回説明し直す必要はない。**
前回の続きから話せる。

答えのうち後で役に立ちそうなものは `notes/` に溜まっていく。
同じことを二度聞かなくて済むように。
